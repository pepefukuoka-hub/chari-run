# チャリラン

昔ながらの「チャリ走」風の、自転車ジャンプゲームです。ブラウザで開けばすぐ遊べます。
（本作は個人の趣味で作った自作ゲームで、元のゲームとは関係ありません）

## 遊び方

- 自転車は自動で走ります。
- 画面の長押し（タップ、またはスペースキー）でジャンプをためて、離すと飛びます。長くためるほど高く・遠くへ飛びます。
- 障害物（段ボール、タイヤ、車）の側面に当たると転倒です。上には乗って走れます。
- 走った距離（m）がスコアです。ベスト記録はブラウザに保存されます。

## ビルド方法

ソースは `src/main.js` です。次のコマンドで、完成品 `docs/index.html`（1ファイル）を作ります。

```
npm run build
```

## 注意書き

- スマートフォンとパソコン、両方に対応しています。
- 音は出ません。
