# ころんの空島アドベンチャー

ブラウザで遊べる 3D アクションゲームです。空に浮かぶ島を走って跳んで、「ひかりの種」を集めます。
外部ライブラリを使わず、WebGL2 で描いています。完成品は `docs/index.html` の1ファイルです。

## 目的

空島のあちこちにある「ひかりの種」8こを集めるとクリアです。タイムはベスト記録として保存されます。

## 遊び方（パソコン）

- 移動：WASD / 矢印キー
- ジャンプ：スペース（着地してすぐ続けて押すと、2段・3段ジャンプ。長押しで高く）
- パンチ：J（3回まで続く。3回目はまわしげり。走りジャンプ中に押すとダイブ）
- しゃがむ：Shift
  - 空中で押すとヒップドロップ（着地直後のジャンプは大ジャンプ）
  - 走りながらしゃがんでジャンプで幅とび、止まってしゃがんでジャンプでバク宙
  - 坂でしゃがむとすべり降りる
- 走りながら逆に入れるとブレーキ。ブレーキ中にジャンプで「くるりんジャンプ」
- 壁に向かって飛び、当たった瞬間にジャンプで壁キック
- カメラ：Q・E またはマウスでドラッグ、ホイール／R で遠近、F で真後ろへ
- ポーズ：Esc（効果音・BGM の ON/OFF、はじめから、操作説明）

## 遊び方（スマホ・ゲームパッド）

- スマホは横向きがおすすめです。画面左をなぞって移動、右側のボタンでジャンプ・パンチ・しゃがむ、右側をドラッグでカメラ、右側を2回タップでカメラを後ろへ。
- 「しゃがむ」から「ジャンプ」へ指をすべらせると、幅とび・バク宙ができます。
- ゲームパッドにも対応しています。

## ビルド方法

ソースは `src/js/*.js`（ファイル名の順に連結）です。次のコマンドで `docs/index.html` を作ります。

```
npm run build
```
