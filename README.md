# ころんの空島アドベンチャー

ブラウザで遊べる 3D アクションゲームです。空に浮かぶ島を走って跳んで、「ひかりの種」を集めます。
外部ライブラリを使わず、WebGL2 で描いています。完成品は `docs/index.html` の1ファイルです。

## 遊び方（パソコン）

- 移動：WASD / 矢印キー
- ジャンプ：スペース（着地してすぐ続けて押すと、2段・3段ジャンプ）
- パンチ：J
- しゃがむ：Shift（空中で押すとヒップドロップ、走りながらしゃがんでジャンプで幅とび、止まってしゃがんでジャンプでバク宙）
- 壁に向かって飛んで、当たった瞬間にジャンプで壁キック
- カメラ：Q・E またはマウスでドラッグ、R で遠近切りかえ、Esc でポーズ

スマートフォンでは、画面左をなぞって移動、右側のボタンで操作します。ゲームパッドにも対応しています。

## ビルド方法

ソースは `src/js/*.js`（ファイル名の順に連結）です。次のコマンドで `docs/index.html` を作ります。

```
npm run build
```
